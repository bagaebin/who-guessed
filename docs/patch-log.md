### 2025-12-5 Patch 10 — 프롬프트 단발성 및 AppearanceCore 고정 명시
- **목표**
  - 각 이미지 생성 기수가 **해당 턴의 질문·답변**만으로 프롬프트를 구성한다는 점을 명확히 한다.
  - 4기에서도 네 번째 질문·답변 프롬프트로 12장을 생성하고, 분기 추론 체인을 유지하지 않는다는 사실을 문서에 반영한다.
  - 생성된 이미지를 분석해 얻은 AppearanceCore가 생성 시점에 고정되며 이후 제거 단계에서 그대로 사용됨을 명시한다.
- **변경 범위**
  - `docs/spec.md`: 진행 시나리오와 phase 정의에 턴 단위 프롬프트 사용과 AppearanceCore 고정 시점을 반영.
  - `docs/gameplay-experience.md`: 게임 흐름과 단계 규칙에 동일 내용을 반영하고 분기 체인 부재를 강조.
- **동작 시나리오**
  1. 플레이어가 현재 질문에 답하면 질문·답변 조합을 영어 형용구로 만들어 기본 이미지 프롬프트에 삽입한다.
  2. 해당 턴 프롬프트로 기수별 요구 장수(1·3·8·12)를 생성하고, 생성 직후 이미지 분석 결과로 AppearanceCore를 채워 넣은 뒤 고정한다.
  3. 4기에서도 네 번째 질문·답변만으로 12장을 생성·분석하고 AppearanceCore를 최신화한 후 기존 제거 단계로 전환한다.
- **검증/테스트**
  - [ ] 시나리오와 단계 규칙 모두에서 누적 맥락 대신 턴 단발 프롬프트 사용이 서술되었는지 확인
  - [ ] AppearanceCore가 생성 직후 고정되고 제거 단계에서 사용된다는 점이 명시되었는지 확인
  - [ ] 분기 추론 체인이 없음을 명확히 언급했는지 확인

### 2025-12-4 Patch 9 — 질문·답변 기반 이미지 프롬프트 및 체인 단순화 문서화
- **목표**
  - 질문 텍스트와 플레이어 답변을 영어 형용구로 요약해 기본 이미지 프롬프트에 삽입하는 흐름을 스펙에 추가합니다.
  - 각 기수는 프롬프트 1회로 필요한 장수를 생성하고, 생성 이미지 분석 결과로 AppearanceCore를 갱신하며 기존 분기 추론 체인을 유지하지 않는다고 명시합니다.
  - 이미지 생성 4기 이후 기존 제거 루프(early/mid/late)는 변경 없이 이어진다는 점을 강조합니다.
- **변경 범위**
  - `docs/spec.md`: 진행 시나리오와 phase 정의에 질문·답변 기반 프롬프트, 이미지 분석 후 AppearanceCore 갱신, 체인 미보존 규칙을 추가.
  - `docs/gameplay-experience.md`: UX 흐름과 단계 규칙에 동일한 프롬프트/분석 기반 생성 절차와 슬롯 확장 규칙을 반영.
- **동작 시나리오**
  1. 매 턴 질문+답변을 영어 형용구로 변환하고, 화이트 배경·증명사진·사실적 스타일 프롬프트에 삽입해 이미지 생성 요청을 보냅니다.
  2. 기수별 요구 장수(1·3·8·12)를 한 번의 프롬프트로 생성하고, 생성 이미지 분석 결과로 AppearanceCore를 채워 빈 슬롯을 확장/채움.
  3. 4기에서도 새 텍스트를 동일 방식으로 적용해 12장을 생성·분석하고 AppearanceCore를 갱신한 뒤, early/mid/late 제거 단계로 전환합니다.
- **검증/테스트**
  - [ ] 시나리오와 단계 정의 모두에서 질문·답변 기반 프롬프트/이미지 분석 흐름이 일관되게 서술되었는지 확인
  - [ ] 분기 추론 체인 미보존 및 4기 이후 기존 제거 루프 유지 규칙이 명확히 언급되었는지 확인

### 2025-12-3 Patch 7 — 이미지 생성 4기 갱신 및 슬롯 증식 규칙 반영
- **목표**
  - 이미지 생성 4기에서 네 번째 텍스트 입력으로 12개 추론 체인을 모두 갱신한 뒤 이미지를 재생성한다는 요구를 명확히 문서화합니다.
  - 이미지 생성 단계별로 필요한 빈 슬롯을 순차적으로 생성·배치하는 규칙(1칸 → 4칸 → 8칸 → 12칸)을 정의해 보드가 점진적으로 확장되도록 합니다.
- **변경 범위**
  - `docs/spec.md`: 단계별 슬롯 증식과 4기 추론 갱신 규칙을 시나리오 및 phase 정의에 추가.
  - `docs/gameplay-experience.md`: UX 흐름과 phase 규칙에 슬롯 생성 타이밍과 4기 갱신 조건을 반영.
- **동작 시나리오**
  1. 게임 시작 시 중앙에 빈 슬롯 1개만 표시한다.
  2. 1기 이미지 생성 후 2기 진입 시 3개 빈 슬롯을 추가(총 4칸), 3기 진입 시 8칸, 4기 진입 시 12칸까지 확장하며 각 기수 요구량만큼 이미지를 채운다.
  3. 4기에서는 네 번째 텍스트 입력을 받아 기존 12개 추론 체인 모두를 최신 AppearanceCore로 갱신한 뒤 이미지화한다.
  4. 4기 종료 후 기존 early/mid/late 제거 루프로 전환한다.
- **검증/테스트**
  - [ ] 4기에서 새 텍스트 입력이 12개 추론 체인 업데이트로 이어진다는 설명이 명시되어 있는지 검토
  - [ ] 슬롯 확장(1→4→8→12칸) 타이밍과 배치 규칙이 단계 정의와 시나리오에 일관되게 반영되어 있는지 확인
