# 패치 로그

후속 패치를 추가할 때마다 아래 "패치 이력" 항목에 새 섹션을 append 해 주세요.

## 문서 구조 가이드
- **목표**: 패치가 달성해야 할 사용자 가치와 UX 요구를 간결히 기재합니다.
- **변경 범위**: 영향을 받는 파일과 책임을 나열합니다.
- **동작 시나리오**: 사용자가 경험할 구체적 플로우를 순서대로 기술합니다.
- **구현 메모**: 의존 관계, API 계약, 예외 처리 등 구현 시 유의사항을 기록합니다.
- **검증/테스트**: 수동·자동 테스트 항목을 체크리스트로 남깁니다.

## 패치 이력

### 2025-12-3 Patch 5 — 말풍선 스케일 재조정
- **목표**
  - 3D 월드 말풍선이 화면 대비 지나치게 작게 보이지 않도록 스케일 계산과 CSS 타이포/레이아웃을 재조정합니다.
- **변경 범위**
  - `src/components/PlayerCameraTile.tsx`: `Html`을 `transform` 모드로 전환하고 distanceFactor를 더 넓은 클램프로 재산정해 해상도/거리 변화에 따라 말풍선이 큼직하게 유지되도록 함.
  - `src/styles.css`: 말풍선 컨테이너 폭·패딩·폰트 크기와 입력/버튼 패딩을 확대해 UI 본문 대비 읽기 쉬운 크기 확보.
- **동작 시나리오**
  1. 화면 크기가 커도 3D 말풍선이 눈에 띄게 확대되어 입력 필드와 버튼이 본문 텍스트와 비슷한 크기로 표시됩니다.
  2. 뷰포트 리사이즈 시에도 distanceFactor 보정으로 말풍선이 과도하게 작아지지 않습니다.
- **검증/테스트**
  - [ ] 1440p 이상 해상도에서 말풍선 폰트/입력/버튼 크기가 본문 UI와 균형 있게 보이는지 확인
  - [ ] 뷰포트 크기를 줄여도 말풍선이 이전보다 작게 줄어들지 않는지 확인

### 2025-12-4 Patch 6 — 애니메이션 스펙 구현
- **목표**
  - `animation-spec.md`에 정의된 인트로 드롭, 카메라 줌 인, 타일 제거 시네마틱, 카메라 복귀 애니메이션을 반영합니다.
- **변경 범위**
  - `src/components/Board3D.tsx`: 인트로 드롭 수량·타이밍 조정, 기본 카메라/자동 틸트 유지, 제거 시 카메라 포커스-홀드-줌아웃 시퀀스 구현 및 OrbitControls 잠금 처리.
  - `src/components/TileCard.tsx`, `src/utils/tileStyleGuide.ts`: 타일 전/후 상태 기울기, 위치, 불투명도 스펙 일치.
  - `docs/animation-spec.md` 참조 UX 흐름을 따라 추가 상태 전환 및 오프셋 계산.
- **동작 시나리오**
  1. 시작 시 무작위 2장의 타일이 420ms 간격으로 4.5u 높이에서 순차 낙하하며, 이후 카메라가 전면(0,4.2,15)에서 기본 시야로 줌 인합니다.
  2. LLM 응답으로 타일이 제거되면 오름차순으로 각 타일을 포커스하며 앞쪽에서 0.5초씩 보여주고, 마지막에는 와이드샷(0,4.2,15)으로 복귀합니다.
  3. 시네마틱 중 OrbitControls가 잠금되고, 완료 후 조작이 다시 허용됩니다.
- **검증/테스트**
  - [ ] 초기 인트로에서 2장의 타일만 순차적으로 드롭되는지 확인
  - [ ] 카메라가 전면 뷰에서 기본 시야로 부드럽게 이동하는지 확인
  - [ ] 타일 제거 후 각 타일을 카메라가 포커스하고 0.5초 유지한 뒤 와이드샷으로 돌아오는지 확인
  - [ ] 시네마틱 동안 카메라 조작이 잠금되는지 확인

### 2025-12-3 Patch 4 — 말풍선 크기 자동 보정
- **목표**
  - 3D 월드 내 플레이어 말풍선의 가독성을 높이기 위해 화면 크기에 맞춰 자동으로 스케일을 보정합니다.
  - 기존 웹 UI 본문의 텍스트 크기와 말풍선 내부 텍스트 크기가 안정적으로 일치하도록 합니다.
- **변경 범위**
  - `src/components/PlayerCameraTile.tsx`: 뷰포트 너비를 기반으로 말풍선 `Html` distanceFactor를 동적으로 계산.
  - `src/styles.css`: 말풍선 컨테이너·입력·버튼의 크기/폰트를 `clamp` 기반으로 확장해 UI 본문 대비 읽기 쉬운 크기 유지.
- **동작 시나리오**
  1. 화면 해상도와 비율에 따라 말풍선이 자동으로 확대/축소되어, 3D 월드에서도 본문 텍스트와 유사한 크기로 표시됩니다.
  2. 입력 필드와 버튼을 포함한 말풍선 내부 UI가 여유 있는 패딩과 폰트 크기로 표시됩니다.
- **검증/테스트**
  - [ ] 데스크톱 해상도에서 말풍선 크기가 기존 대비 커져 텍스트가 명확하게 보이는지 확인
  - [ ] 뷰포트 크기를 변경해도 말풍선 텍스트 크기가 UI 본문 대비 지나치게 작거나 크지 않은지 확인

### 2025-12-3 Patch 1 — LLM 말풍선 입력/전송 및 카메라 타일 스타일 통일
- **목표**
  - 플레이어 카메라 타일을 `tileStyleGuide`의 캐릭터 타일 룩앤필(색상, 질감/라이팅, border-radius)과 동일하게 통일합니다.
  - 3D 월드 말풍선에서 LLM 자기소개 텍스트를 작성/전송할 수 있도록 버튼·엔터 전송을 지원합니다.
  - 마우스 카메라 이동 후에도 키 입력 시 말풍선에 문자가 입력되고, 카메라와 포커스가 플레이어 카메라 타일로 재정렬됩니다.
  - 한글 입력 시 2회 중복 입력되는 버그를 방지합니다.
- **변경 범위**
  - `src/components/PlayerCameraTile.tsx`: 타일 스타일 개선, 말풍선 입력/전송 UX, 글로벌 키 입력 처리, 카메라 포커스 연동.
  - `src/components/Board3D.tsx`: 카메라 포커스 함수 제공 및 OrbitControls 참조 관리.
  - `src/state/gameStore.ts`: 말풍선/패널에서 공유할 자기소개 텍스트 상태 및 setter 추가.
  - `src/components/UiPanel.tsx`: 스토어 기반 자기소개 입력값 공유 및 전송 로직 정리.
  - `src/styles.css`: 말풍선 레이아웃과 버튼 스타일 확장.
- **동작 시나리오**
  1. 사용자가 3D 보드에서 문자 키를 누르면(캔버스나 본문에 포커스된 상태) 말풍선 입력이 자동 포커스되며, 누른 문자가 말풍선 입력 필드에 추가되고 카메라는 플레이어 카메라 타일을 향해 재정렬됩니다.
  2. 말풍선 내부 전송 버튼 또는 엔터 키로 LLM 추론을 전송할 수 있으며, 우측 패널 입력창과 동일한 텍스트 상태를 공유합니다.
  3. 한글 IME 조합 상태(`isComposing`)에서는 수동 문자 삽입을 건너뛰어 중복 입력을 방지합니다.
  4. 플레이어 카메라 타일은 캐릭터 타일과 동일한 색상 팔레트, 재질 러프니스/메탈니스, 라운드 박스를 사용해 시각적으로 통일됩니다.
- **구현 메모**
  - 타일 스타일: `TILE_COLOR_GUIDE.active`를 활용해 RoundedBox 재질과 상단 액센트 색상을 통일합니다.
  - 카메라 포커스: OrbitControls ref와 초기 카메라-타겟 오프셋을 이용해 타겟을 플레이어 카메라 타일 위치로 맞추고 거리를 유지합니다.
  - 입력 상태: Zustand에 `playerText`/`setPlayerText`를 추가하고, 패널과 말풍선 모두 이 상태를 사용하도록 수정합니다.
  - 키 이벤트: global `keydown`에서 입력/textarea/contentEditable 포커스는 무시하고, 단일 문자 키에 한해 포커스 이동과 상태 업데이트를 수행합니다.
- **검증/테스트**
  - [ ] 3D 보드 포커스 상태에서 단일 문자 입력 시 말풍선 필드가 포커스되고 텍스트가 한 번만 입력되는지 확인
  - [ ] IME 조합(한글) 입력 시 중복 입력이 발생하지 않는지 확인
  - [ ] 전송 버튼 클릭과 엔터 입력 모두 동일한 전송 핸들러를 호출하는지 확인
  - [ ] 말풍선에서 전송 후 우측 패널 입력 상태가 동기화되는지 확인
  - [ ] 플레이어 카메라 타일이 캐릭터 타일과 동일한 색상/재질/라운드 박스를 사용하는지 시각 확인
