# 패치 로그

후속 패치를 추가할 때마다 아래 "패치 이력" 항목에 새 섹션을 append 해 주세요.

## 문서 구조 가이드
- **목표**: 패치가 달성해야 할 사용자 가치와 UX 요구를 간결히 기재합니다.
- **변경 범위**: 영향을 받는 파일과 책임을 나열합니다.
- **동작 시나리오**: 사용자가 경험할 구체적 플로우를 순서대로 기술합니다.
- **구현 메모**: 의존 관계, API 계약, 예외 처리 등 구현 시 유의사항을 기록합니다.
- **검증/테스트**: 수동·자동 테스트 항목을 체크리스트로 남깁니다.

## 패치 이력

### 2025-12-3 Patch 3 — LLM 프로필 갱신 허용
- **목표**
  - 플레이어가 추가 소개를 전송할 때마다 LLM 추정 프로필을 최신 상태로 반영합니다.
- **변경 범위**
  - `src/state/gameStore.ts`: 후속 응답에서도 `playerProfile`을 덮어써 최신 추정치를 유지.
  - `docs/spec.md`, `docs/gameplay-experience.md`: 프로필 갱신 정책을 사양에 반영.
- **동작 시나리오**
  1. 플레이어가 새로운 텍스트를 입력해 전송하면 LLM 응답의 프로필이 스토어에 항상 반영됩니다.
  2. 후속 라운드에서도 최신 프로필을 우측 패널에서 확인할 수 있습니다.
- **검증/테스트**
  - [ ] 연속 전송 시 프로필 값이 응답에 따라 덮어써지는지 확인
  - [ ] 기존 타일 제거·단계 업데이트 흐름이 유지되는지 확인

### 2025-12-3 Patch 2 — 카메라/타일 안내 텍스트 제거
- **목표**
  - 3D 캐릭터 타일 위 일련번호 텍스트와 플레이어 카메라 타일의 안내 문구를 제거해 화면을 깔끔하게 유지합니다.
- **변경 범위**
  - `src/components/TileCard.tsx`: 캐릭터 타일 상단의 일련번호 텍스트 제거.
  - `src/components/PlayerCameraTile.tsx`: 카메라 타일 상단 라벨과 말풍선 헤더/힌트 문구 제거.
- **동작 시나리오**
  1. 플레이어 카메라 타일 상단에 문구가 표시되지 않습니다.
  2. 말풍선 입력창에는 헤더와 힌트 텍스트 없이 입력 필드와 전송 버튼만 노출됩니다.
  3. 캐릭터 타일 상단의 번호 라벨이 사라집니다.
- **검증/테스트**
  - [ ] 플레이어 카메라 타일 상단에 문구가 노출되지 않는지 확인
  - [ ] 말풍선 입력 영역이 헤더/힌트 없이 정상 입력·전송되는지 확인
  - [ ] 캐릭터 타일 상단에 번호 텍스트가 표시되지 않는지 확인

### 2025-12-3 Patch 1 — LLM 말풍선 입력/전송 및 카메라 타일 스타일 통일
- **목표**
  - 플레이어 카메라 타일을 `tileStyleGuide`의 캐릭터 타일 룩앤필(색상, 질감/라이팅, border-radius)과 동일하게 통일합니다.
  - 3D 월드 말풍선에서 LLM 자기소개 텍스트를 작성/전송할 수 있도록 버튼·엔터 전송을 지원합니다.
  - 마우스 카메라 이동 후에도 키 입력 시 말풍선에 문자가 입력되고, 카메라와 포커스가 플레이어 카메라 타일로 재정렬됩니다.
  - 한글 입력 시 2회 중복 입력되는 버그를 방지합니다.
- **변경 범위**
  - `src/components/PlayerCameraTile.tsx`: 타일 스타일 개선, 말풍선 입력/전송 UX, 글로벌 키 입력 처리, 카메라 포커스 연동.
  - `src/components/Board3D.tsx`: 카메라 포커스 함수 제공 및 OrbitControls 참조 관리.
  - `src/state/gameStore.ts`: 말풍선/패널에서 공유할 자기소개 텍스트 상태 및 setter 추가.
  - `src/components/UiPanel.tsx`: 스토어 기반 자기소개 입력값 공유 및 전송 로직 정리.
  - `src/styles.css`: 말풍선 레이아웃과 버튼 스타일 확장.
- **동작 시나리오**
  1. 사용자가 3D 보드에서 문자 키를 누르면(캔버스나 본문에 포커스된 상태) 말풍선 입력이 자동 포커스되며, 누른 문자가 말풍선 입력 필드에 추가되고 카메라는 플레이어 카메라 타일을 향해 재정렬됩니다.
  2. 말풍선 내부 전송 버튼 또는 엔터 키로 LLM 추론을 전송할 수 있으며, 우측 패널 입력창과 동일한 텍스트 상태를 공유합니다.
  3. 한글 IME 조합 상태(`isComposing`)에서는 수동 문자 삽입을 건너뛰어 중복 입력을 방지합니다.
  4. 플레이어 카메라 타일은 캐릭터 타일과 동일한 색상 팔레트, 재질 러프니스/메탈니스, 라운드 박스를 사용해 시각적으로 통일됩니다.
- **구현 메모**
  - 타일 스타일: `TILE_COLOR_GUIDE.active`를 활용해 RoundedBox 재질과 상단 액센트 색상을 통일합니다.
  - 카메라 포커스: OrbitControls ref와 초기 카메라-타겟 오프셋을 이용해 타겟을 플레이어 카메라 타일 위치로 맞추고 거리를 유지합니다.
  - 입력 상태: Zustand에 `playerText`/`setPlayerText`를 추가하고, 패널과 말풍선 모두 이 상태를 사용하도록 수정합니다.
  - 키 이벤트: global `keydown`에서 입력/textarea/contentEditable 포커스는 무시하고, 단일 문자 키에 한해 포커스 이동과 상태 업데이트를 수행합니다.
- **검증/테스트**
  - [ ] 3D 보드 포커스 상태에서 단일 문자 입력 시 말풍선 필드가 포커스되고 텍스트가 한 번만 입력되는지 확인
  - [ ] IME 조합(한글) 입력 시 중복 입력이 발생하지 않는지 확인
  - [ ] 전송 버튼 클릭과 엔터 입력 모두 동일한 전송 핸들러를 호출하는지 확인
  - [ ] 말풍선에서 전송 후 우측 패널 입력 상태가 동기화되는지 확인
  - [ ] 플레이어 카메라 타일이 캐릭터 타일과 동일한 색상/재질/라운드 박스를 사용하는지 시각 확인

### 2025-12-4 Patch 4 — 카메라 자동 시선 보정 및 말풍선 크기 가독성 향상
- **목표**
  - 카메라를 보드 위쪽으로 이동할 때 자동으로 시선이 캐릭터 타일을 향하도록 보정합니다.
  - 3D 월드 말풍선의 크기를 화면 대비 본문 텍스트 크기와 유사하게 자동 스케일링합니다.
- **변경 범위**
  - `src/components/Board3D.tsx`: 카메라 높이(또는 Z축) 이동 시 타겟 Y축을 점진적으로 재정렬해 하향 시선을 유지.
  - `src/components/PlayerCameraTile.tsx`: 카메라와의 거리에 비례해 말풍선 `Html` distanceFactor를 실시간 조정.
- **동작 시나리오**
  1. 사용자가 마우스/트랙패드로 카메라를 위쪽(Z축 방향)으로 이동하면 시선이 자동으로 캐릭터 타일을 향하도록 살짝 아래로 꺾입니다.
  2. 키보드 입력 등으로 플레이어 카메라 타일에 포커스-인할 때는 시선 보정 쿨다운이 적용돼 기본 구도로 초기화됩니다.
  3. 말풍선은 카메라와의 거리에 따라 자동으로 스케일링되어 화면 본문 텍스트 크기와 유사한 가독성을 유지합니다.
- **검증/테스트**
  - [ ] 카메라를 위로 이동한 뒤에도 타일 영역이 시야에 안정적으로 유지되는지 확인
  - [ ] 포커스-인 액션 이후 카메라 각도가 초기 상태로 돌아가는지 확인
  - [ ] 카메라가 멀어져도 말풍선 텍스트 크기가 UI 본문 수준으로 유지되는지 확인

### 2025-12-4 Patch 5 — 포커스 구도/말풍선 시야 안정화
- **목표**
  - 키 입력으로 카메라가 플레이어 타일을 향할 때 보드가 화면의 절반 이상 유지되도록 타겟 구도를 보정합니다.
  - 포커스 이동 시 말풍선이 과도하게 커져 프레임 밖으로 밀려나는 문제를 방지합니다.
- **변경 범위**
  - `src/components/Board3D.tsx`: 포커스 타겟을 보드 중심과 플레이어 타일 사이로 블렌딩해 시야를 균형 있게 유지.
  - `src/components/PlayerCameraTile.tsx`: 카메라 뷰포트 높이를 활용해 말풍선 `Html` distanceFactor를 계산, 화면 대비 안정적인 크기로 제한.
- **동작 시나리오**
  1. 키보드 입력으로 포커스-인할 때 카메라 타겟이 보드 중심 방향으로 약간 당겨져 보드가 시야에 더 많이 노출됩니다.
  2. 같은 포커스 동작에서도 말풍선은 뷰포트 기반 스케일을 사용해 화면 밖으로 밀려나지 않습니다.
- **검증/테스트**
  - [ ] 포커스-인 이후 보드 영역이 화면 중앙에 안정적으로 잡히는지 확인
  - [ ] 포커스-인 상태에서 말풍선이 화면 밖으로 밀려나지 않는지 확인
