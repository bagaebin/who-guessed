# Who Guessed? 애니메이션 스펙

## 인트로 시퀀스
- **타일 드롭**: 시작 시 무작위 2장의 타일이 지면 위 4.5u 높이에서 순차적으로 낙하. 각 타일은 420ms 간격, 개별 시작 높이 +0.6u 보정.
- **카메라 줌인**: 모든 드롭이 끝나면 카메라가 전면(0, 4.2, 15)에서 보드 중심(0, 1.4, 0)으로 부드럽게 이동.
- **완료**: 줌인 종료 후 사용자 조작 가능.

## 기본 카메라
- 기본 시야: (0, 2, 8) 위치에서 (0, 1.5, 0) 타겟을 바라봄.
- 자동 틸트: 높이에 비례한 최대 1.1rad 자동 틸트로 보드 위를 살짝 굽어봄.
- 인트로 이후에는 OrbitControls의 회전·패닝·줌을 모두 허용하고, 댐핑을 켠 상태로 화면 공간 패닝(screen-space panning)과 넉넉한 줌
  범위(최소 거리 4, 최대 거리 60)로 사용자가 드래그만으로도 시점을 자유롭게 이동할 수 있다.

## 카메라 포커스 및 입력 동작
- 인트로 이후에는 **자유 OrbitControls**와 **키보드 트리거 포커스** 두 상태만 남는다. 자유 회전/패닝/줌을 방해하는 후속 자동 타겟 보간이나 중앙 락은 모두 비활성화한다.
- 키보드 입력이 시작되면 플레이어 카메라 타일을 OrbitControls 타겟으로 재설정하고, **현재 카메라-타겟 오프셋을 보존한 채 한 차례 보정**해 플레이어 시점을 향하게 한다.
- 보정 루틴은 목표 위치(타일)와 오프셋이 수렴하면 바로 중단되어, 이후 회전·패닝 조작 시 카메라가 다시 중앙으로 스냅되지 않는다.
- 버그 원인: 인트로 완료 후에도 카메라 업데이트 루프가 기본 타겟/틸트 보간을 매 프레임 강제해 사용자가 회전해도 다시 중앙 시야로 돌아갔다. 수정 후에는 인트로가 끝나면 카메라 업데이트 루프가 중단되고(포커스 보정 시에만 일시 활성), OrbitControls만 남아 사용자가 둔 프레이밍을 그대로 유지한다.

## 타일 상태
- **활성**: 약 -0.2rad 기울기로 서 있는 상태.
- **제거(Eliminated)**: -90° 이상으로 앞으로 쓰러지며 -0.32u 하강, 불투명도 60%로 감소.
