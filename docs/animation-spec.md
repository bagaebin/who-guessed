# Who Guessed? 애니메이션 스펙

## 인트로 시퀀스
- **타일 드롭**: 시작 시 무작위 2장의 타일이 지면 위 4.5u 높이에서 순차적으로 낙하. 각 타일은 420ms 간격, 개별 시작 높이 +0.6u 보정.
- **카메라**: 인트로 동안에도 단일 고정 시점(보드 전체를 담는 관망각)을 유지한다. 이동·줌·틸트 애니메이션은 없다.

## 기본 카메라
- 고정 시야: 격자의 중심(0, y, 0)을 바라보는 단일 구도만 제공한다. 시작 이후에도 카메라 위치·타겟은 업데이트되지 않고, OrbitControls/포커스 트리거 같은 사용자 조작 기능도 포함되지 않는다.
- 목적: 모든 타일과 플레이어 카메라 타일이 한 화면에 담기는 안정된 구도를 유지해 시점 스냅이나 락 이슈를 근본적으로 제거한다.

## 타일 상태
- **활성**: 약 -0.2rad 기울기로 서 있는 상태.
- **제거(Eliminated)**: -90° 이상으로 앞으로 쓰러지며 -0.32u 하강, 불투명도 60%로 감소.
