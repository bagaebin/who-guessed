# Who Guessed? 애니메이션 스펙

## 기본 카메라
- 고정 시야: 보드 중심을 바라보는 단일 구도만 제공하며, 초기 설정 이후에도 위치·타겟이 바뀌지 않는다.
- 목적: 5열 계단형 보드와 전면 카메라 타일을 한 화면에 안정적으로 담아 시점 스냅이나 포커스 보정 이슈를 제거한다.

## 타일 상태
- **활성**: 약 -0.2rad 전방 기울기로 서 있으며 불투명도 100%.
- **제거(Eliminated)**: -90° 이상으로 앞으로 쓰러지며 약 -0.25u 하강, 불투명도는 스타일 가이드에 따라 감소한다.
- **인트로 낙하**: 체인 공개 시 스프링 모션으로 위에서 내려오며, 완료 시 onComplete 훅으로 다음 타일을 이어서 드롭한다.
