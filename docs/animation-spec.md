# Who Guessed? 애니메이션 스펙

## 인트로 시퀀스
- **타일 드롭**: 시작 시 무작위 2장의 타일이 지면 위 4.5u 높이에서 순차적으로 낙하. 각 타일은 420ms 간격, 개별 시작 높이 +0.6u 보정.
- **카메라 줌인**: 모든 드롭이 끝나면 카메라가 전면(0, 4.2, 15)에서 보드 중심(0, 1.4, 0)으로 부드럽게 이동.
- **완료**: 줌인 종료 후 사용자 조작 가능.

## 기본 카메라
- 기본 시야: (0, 2, 8) 위치에서 (0, 1.5, 0) 타겟을 바라봄.
- 자동 틸트: 높이에 비례한 최대 1.1rad 자동 틸트로 보드 위를 살짝 굽어봄.

## 타일 상태
- **활성**: 약 -0.2rad 기울기로 서 있는 상태.
- **제거(Eliminated)**: -90° 이상으로 앞으로 쓰러지며 -0.32u 하강, 불투명도 60%로 감소.

## 제거 시네마틱
- **트리거**: 한 번의 텍스트 입력으로 LLM 응답이 도착해 타일이 제거될 때 시작. 새로 제거된 타일을 일련번호 오름차순으로 정렬해 순회.
- **포커스-인**: 각 제거 대상마다 카메라가 해당 타일 상단(+0.25u)에 맞춰 (0, +1.4, +4.4) 오프셋 위치로 이동하며 줌 인. 이동 곡선은 지수 감쇠 보간(lerp 2.6).
- **쓰러짐 연출**: 포커스에 도달한 타일이 그 순간 단 한 번 넘어지며, 이미 넘어간 타일은 재생되지 않음.
- **홀드**: 카메라 도착 후 0.5초간 해당 장면 유지.
- **다음 타일**: 다음 제거 타일로 동일 시퀀스 반복.
- **줌 아웃 피날레**: 모든 제거 타일을 보여준 뒤, 카메라가 전경 와이드샷(0, 4.2, 15) / 타겟(0, 1.4, 0)으로 복귀(lerp 1.9)해 전체 보드를 노출하며 마무리.
- **조작 잠금**: 시네마틱 동안 OrbitControls 비활성화; 완료 후 다시 활성화.
